STICK VARIO / INSTALLAZIONE

Dal browser allo Stick.

Prepara una versione, collega il cavo USB e scegli se provarla in RAM o conservarla sul dispositivo.

Laboratorio, configurazione e installazione sono tre pagine dello stesso sito. Nessuna repository GitHub è necessaria per provare questa versione locale.

Il programma del vario è un’app MicroPython su UIFlow2. La modalità normale conserva UIFlow e le impostazioni già salvate.
01

Scegli la versione

Locale, GitHub oppure un tuo file

Se GitHub impedisce il download nel browser, usa il mirror GitHub Pages oppure scarica i file e selezionali qui.

Per i binari di sistema serve un manifest specifico per M5StickS3. Uno ZIP va estratto prima.

Scarica il file selezionato
02

Collega e avvia

USB · Chrome o Edge desktop

Scollega prima lo Stick dal laboratorio, dal configuratore e dagli altri programmi che usano la stessa porta. Questa operazione interrompe il vario in esecuzione.

Prova la versione senza scrivere file. Dopo un riavvio dovrà essere ricaricata.

Con avvio automatico selezionato salva l’app, conserva il precedente main.py e installa un piccolo launcher. UIFlow e boot.py restano intatti. Tieni B all’accensione per tornare al menu UIFlow al riavvio.

Immagine di sistema ESP32-S3: può sostituire UIFlow e cancellare applicazioni e configurazioni. Serve un’immagine completa preparata per questo Stick, non il nostro script .py.

Il flasher ESP Web Tools si carica solo su richiesta. Non viene avviato durante le prove dell’app MicroPython.

Opzioni sviluppatore · avvio UIFlow

Richiedono una connessione USB all’installer e interrompono il vario attivo. Queste sono le tre opzioni verificate nel sorgente UIFlow; nessuna password di rete viene letta.

Collega lo Stick per leggere le impostazioni.

Le modifiche di modalità valgono dal prossimo riavvio. Ripristina rimette il main.py e l’opzione originali, senza cancellare l’app del vario o le sue impostazioni.
